# AI Workforce Impact Prediction & Career Analytics System

An End-to-End Machine Learning project that predicts potential workforce outcomes in the age of Artificial Intelligence.

## Project Overview

This project was developed as a graduation project during the **National Telecommunication Institute (NTI)** training program.

The system analyzes workforce-related data and predicts the potential impact of AI adoption on employees, classifying outcomes into four categories:

- Employed
- Reskilled
- Career Change
- Unemployed

## Dataset

- Approximately 100,000 employee records.
- 73 features.
- Multiclass Classification Problem.

## Machine Learning Models

We experimented with multiple classification algorithms:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Naive Bayes
- XGBoost
